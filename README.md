 Brew Haven Coffee – Business Website

A simple, responsive business website created using HTML, CSS, and JavaScript.  
This project demonstrates basic front-end web development concepts such as semantic HTML, responsive design, and JavaScript interactivity.



 Project Overview

Brew Haven Coffee is a fictional local coffee shop website that provides:
Business information
Menu details
Contact form for customers

The website is fully responsive and works on mobile, tablet, and desktop devices.



Technologies Used

HTML5 – Structure and content
CSS3 – Styling and responsive design
JavaScript – Interactivity and form handling



Project Structure




Pages Description

Home Page: Introduction to the coffee shop
About Page: Story and mission of the business
Menu Page: List of coffee items and prices
Contact Page: Contact form with JavaScript validation



 Features

Responsive layout (mobile-first approach)
Clean and semantic HTML structure
Reusable navigation bar
JavaScript-powered contact form
Beginner-friendly code



How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Double-click `index.html`
4. The website will open in your browser

_No server or installation required_
